## Instrucciones generales

El objetivo de esta prueba es crear una pregunta simple de introducción a la programación, incluyendo el código solución y el enunciado. Además, se evaluará el manejo básico de Git, que es esencial para el trabajo durante la ayudantía.

## Tareas a realizar

### 1. Crear una nueva branch
Primero, debes crear una nueva rama en el repositorio asignado llamada `development`. Todas las tareas listadas a continuación deben realizarse en dicha rama.

### 2. Idear una Pregunta
Debes idear una pregunta que evalúe algún contenido de introducción a la programación (al nivel del curso) y escribir tanto el enunciado como el código solución de esta. La complejidad de la pregunta queda a su criterio; solo se pide que no sea extremadamente simple; se valorará especialmente la creatividad. Como recordatorio, los contenidos del curso relevantes para las tareas son: control de flujo, funciones, strings, listas, recursión, archivos y OOP. **Se puede elegir cualquier combinación de ellos**.

#### 2.1 Enunciado:
Debes redactar un enunciado para tu pregunta; para ello, debes rellenar el archivo ``instructions.md`` en la carpeta ``Enunciado/``. Debes borrar las instrucciones de cada apartado y rellenar con lo que corresponda.

#### 2.1 Código solución:
Debes escribir el código solución de la pregunta; este debe guardarse en la carpeta `Codigo/` con el nombre `code.py`.

### 3. Crear una pull request

Cuando esté todo listo, debes hacer push a la rama ``development`` y crear una pull request a la rama ``main``. En la PR debes incluir tu nombre y correo UC para poder identificarte.
